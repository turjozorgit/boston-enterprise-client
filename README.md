# Boston Enterprise

A private, static website prototype for a Government Authorised Customs Clearing & Forwarding Agent with 32–33 years of professional experience.

## Run locally

`npm start` serves `public/` on port 8080. No installation or build is required.

## Enquiry behaviour

The guided flow supports customs clearing, forwarding and coordination, documentation support, and general guidance. It adapts guidance for new and experienced visitors. Details remain in page memory. There are no submission endpoints, analytics, external form providers or browser storage. Refreshing clears entered data. Visitors may copy or download their draft; nothing is sent.

The hero image is generated illustrative port imagery, not a photograph identifying a specific location. Proposed service wording is indicative; scope and availability are confirmed after shipment review. No contact details or testimonials have been fabricated.

## Hosting

Hosted on Sites with owner-only access. The source assets are in `public`; `npm run build` copies them to the deployed static root `dist`. Preserve the project ID in `.openai/hosting.json` and the private access policy for subsequent changes.
